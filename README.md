# Scoreboard Tweaks (Fabric, Minecraft 1.21.11)

Funktionen:
- Scoreboard (rechts) kleiner/größer machen: 25 % bis 300 %
- Scoreboard-Hintergrund ausblenden
- Zahlen (Punktestände) ausblenden

Einstellungen: Taste **K** (in den Steuerungs-Einstellungen änderbar) öffnet das Menü.
Die Werte werden in `config/scoreboardtweaks.json` gespeichert.

Bauen:
    ./gradlew build        (Windows: gradlew.bat build)
Die fertige Mod liegt danach in `build/libs/scoreboardtweaks-1.0.0.jar`
(NICHT die Datei mit `-sources`). Benötigt Fabric Loader + Fabric API.
